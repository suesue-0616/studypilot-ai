StudyPilot AI 第2版 — GitHub Pages公開用

【公開手順】
1. GitHubにログインし、New repository で新しい公開リポジトリを作成します。
2. リポジトリ名は studypilot-ai などにします。Publicを選び、Create repository。
3. Add file → Upload files を選び、このZIPを展開して出てくる index.html と README.md をアップロードします。
4. Commit changes を押します。
5. Settings → Pages → Build and deployment で Deploy from a branch を選びます。
6. Branch は main、folder は /(root) を選び Save。
7. 数分待ち、Settings → Pages に表示されるURLを開いて動作確認します。

【機能・制限】
- 学校登録、問題作成、学校別問題表示、AI家庭教師デモ、今日のチャレンジ、レベル・ランキング、学習計画、学習記録など。
- v2の追加機能：問題検索、お気に入り、投稿削除、日別学習時間、7日間表示、連続学習日数、JSONバックアップ/復元。
- データは利用者それぞれのブラウザ内に保存され、別の端末や友達とは同期されません。ランキング・問題共有もオンライン同期ではありません。
- AI家庭教師はデモで、本物のAI APIには接続していません。
- 公開サイトに本名、住所、電話番号、学校の詳細など個人情報を入力しないでください。
